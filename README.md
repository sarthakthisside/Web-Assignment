# 🧑‍💻 Sarthak's Portfolio Website

A personal portfolio website built with **pure HTML5 and CSS3** — no JavaScript frameworks, no libraries.

## 🌐 Live Demo
[View Portfolio](https://your-username.github.io/portfolio)

## 📁 Project Structure
```
portfolio/
├── index.html       ← Main HTML file
├── style.css        ← External stylesheet
├── assets/
│   ├── profile.png  ← Your profile photo (replace this)
│   ├── about.jpg    ← About section image (replace this)
│   ├── project1.jpg ← Project screenshot
│   ├── project2.jpg ← Project screenshot
│   └── project3.jpg ← Project screenshot
└── README.md
```

## ✅ Features
- Sticky responsive navbar with smooth scroll
- Hero section with profile photo
- About Me section with bio, education & goals
- Skills section with animated progress bars
- Projects section with cards
- Contact form with HTML5 validation
- Footer with social media links
- Fully responsive (mobile + desktop)
- No JavaScript frameworks — just plain HTML & CSS

## 🚀 How to Use
1. Clone or download this repo
2. Replace placeholder images in `assets/` with your own photos
3. Update your name, bio, skills, and project details in `index.html`
4. Update social media links in the footer
5. Open `index.html` in a browser — done!

## 📤 Deploy on GitHub Pages
1. Push to a GitHub repo
2. Go to **Settings → Pages**
3. Set source to `main` branch, root folder
4. Your site will be live at `https://your-username.github.io/repo-name`
